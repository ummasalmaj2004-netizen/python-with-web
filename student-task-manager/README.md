# Student Task Manager

A beginner-friendly web application built with Python and web technologies.

## Project Goal

The goal of this project is to learn how to connect a web interface with a Python backend and build a practical application.

## Planned Features

- Add tasks
- View tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Organize tasks by category
- Store task information

## Technologies

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- JSON
- GitHub

## Learning Path

This project will gradually develop into a larger application:

Python + Web  
↓  
Python + Web + Database  
↓  
Python + Web + Cloud
